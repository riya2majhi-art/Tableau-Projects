## 🎬 Netflix Dashboard

An interactive **Netflix Dashboard** developed using Tableau to analyze Netflix's content library and identify patterns across movies and TV shows.

### 🔍 Analysis Includes

* 🎬 Movies vs. TV Shows distribution
* 🌍 Content distribution by country
* 📅 Content added over time
* 🎭 Popular genres and categories
* ⭐ Ratings and content classification
* 🎥 Movie and TV Show trends
* 🔎 Interactive filtering for deeper analysis
